 # 3D Gaussian Splatting（高斯泼溅）详解

## 一、技术原理

### 1. 核心思想：放弃网格与神经场

传统 3D 表示有两种主流方案：

| 方案 | 代表 | 优点 | 缺点 |
|---|---|---|---|
| **显式几何** | Mesh、点云 | 渲染快、可编辑 | 拓扑固定、难以表达复杂细节 |
| **隐式场** | NeRF（神经辐射场） | 连续、细节丰富 | 推理慢（光线步进）、难编辑 |

**3D Gaussian Splatting（3DGS）** 提出了一种全新的**显式-可微**表示：
> 用 **数百万个 3D 高斯椭球** 直接表示场景，每个高斯携带颜色、透明度和形状参数，通过**光栅化**而非光线追踪实现实时渲染。

### 2. 3D 高斯的数学定义

一个 3D 高斯分布由以下参数完全定义：

$$G(\mathbf{x}) = e^{-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})}$$

其中：
- $\boldsymbol{\mu} = (x, y, z)$ —— 高斯中心位置
- $\boldsymbol{\Sigma}$ —— **协方差矩阵**（3×3），决定椭球的形状、大小和朝向

**关键技巧：协方差参数化**
直接优化 $\boldsymbol{\Sigma}$ 会导致矩阵不正定（出现负体积）。因此 3DGS 将其分解为：

$$\boldsymbol{\Sigma} = \mathbf{R}\mathbf{S}\mathbf{S}^\top\mathbf{R}^\top$$

- $\mathbf{S}$ —— 缩放矩阵（对角阵，3 个参数 $s_x, s_y, s_z$）
- $\mathbf{R}$ —— 旋转矩阵（用四元数 $q$ 表示，4 个参数）

这样只需优化 7 个参数即可保证 $\boldsymbol{\Sigma}$ 始终半正定。

### 3. 每个高斯携带的完整属性

```
┌─────────────────────────────────────┐
│  3D Gaussian Primitive              │
├─────────────────────────────────────┤
│  Position:     (x, y, z)     [3]    │
│  Rotation:     (qw, qx, qy, qz) [4] │
│  Scale:        (sx, sy, sz)  [3]    │
│  Opacity:      α             [1]    │
│  Color (SH):   (r0..r44,     [45×3] │
│                g0..g44,             │
│                b0..b44)             │
└─────────────────────────────────────┘
```

- **颜色使用球谐函数（Spherical Harmonics, SH）**：不是单一 RGB，而是 0~3 阶共 16 个（或更高阶 45 个）SH 系数，实现**视角相关颜色**（模拟镜面反射、光泽）。
- **不透明度 $\alpha$**：通过 sigmoid 约束到 $[0,1]$，用于 alpha 混合。

### 4. 渲染管线：Splatting → 2D 投影 → 光栅化

这是 3DGS 与 NeRF 最大的区别——**它不用光线追踪，而是用光栅化**：

```
┌─────────────────────────────────────────────────────┐
│              渲染一帧图像的流程                        │
├─────────────────────────────────────────────────────┤
│ 1. 视锥剔除（View Frustum Culling）                  │
│    只保留相机可见的高斯                                │
├─────────────────────────────────────────────────────┤
│ 2. 3D → 2D 投影（EWA Splatting）                     │
│    将每个 3D 高斯投影到图像平面，得到一个 2D 高斯       │
│    使用仿射近似：Σ_2D = J·W·Σ·W^T·J^T                 │
│    J = 投影雅可比矩阵，W = 视图矩阵                     │
├─────────────────────────────────────────────────────┤
│ 3. 深度排序（Tile-based Sorting）                     │
│    将屏幕划分为 16×16 的 tile                          │
│    对每个 tile 内的高斯按深度排序（从前往后）           │
├─────────────────────────────────────────────────────┤
│ 4. α-混合光栅化（Alpha Blending）                     │
│    对每个像素，按深度顺序累积颜色：                      │
│    C = Σ c_i · α_i · T_i                             │
│    T_i = Π(1 - α_j)  （透射率，j < i）                 │
│    直到 T < ε 或遍历完所有高斯                         │
├─────────────────────────────────────────────────────┤
│ 5. 输出图像                                           │
└─────────────────────────────────────────────────────┘
```

**为什么快？**
- 没有 MLP 推理（NeRF 每像素要跑几百次神经网络前向传播）
- 没有光线步进（Volume Rendering 的采样开销）
- 高斯投影后直接用 CUDA 并行光栅化，充分利用 GPU 的 tile-based 架构
- 渲染速度可达 **100+ FPS**（1080p，数百万高斯），而 NeRF 通常只有 0.5~2 FPS

### 5. 训练/优化流程

3DGS 的训练是一个**可微渲染**过程：

```
输入：多视角图像（带相机位姿，通常由 COLMAP 预先计算）
      ↓
初始化：从 COLMAP 稀疏点云生成初始 3D 高斯
      ↓
循环：
  ├─ 前向传播：渲染图像 → 与真实图像计算光度损失（L1 + SSIM）
  ├─ 反向传播：梯度更新高斯参数（位置、旋转、缩放、颜色、透明度）
  └─ 自适应密度控制（每 100 迭代）：
       • 透明度 < ε 的高斯 → 删除（剪枝）
       • 梯度大的区域 → 分裂或克隆高斯（增加细节）
      ↓
输出：训练好的 PLY 文件（高斯参数）
```

**自适应密度控制**是 3DGS 的关键创新：
- **克隆**：对于视图空间梯度大的小高斯，复制一个并沿梯度方向移动
- **分裂**：对于大高斯，分裂为两个较小的高斯（类似细胞分裂）
- **剪枝**：移除几乎透明的高斯
- 这使得模型能自动在复杂区域（如边缘、纹理丰富处）增加高斯密度，在平滑区域减少。

## 二、发展历史

### 1. 前史：传统 Splatting（1990s~2000s）

- **1993 年**：Westover 提出 **Splatting** 算法，用于体数据渲染（Volume Rendering）。核心思想是将体素投影为屏幕上的"足迹"（footprint），用 2D 纹理叠加。
- **2000 年代初**：Zwicker 等人将 Splatting 用于点云渲染（Surfels），用椭圆高斯近似表面元素。
- **局限**：当时没有可微渲染，无法从图像优化；主要用于可视化而非重建。

### 2. 神经辐射场时代（2020~2022）

- **2020 年 8 月**：Mildenhall 等人发表 **NeRF**，用 MLP 隐式表示场景，引发 3D 重建革命。
- **2021~2022 年**：NeRF 生态爆发（Mip-NeRF、Instant-NGP、Plenoxels），但核心瓶颈始终是**渲染速度慢**（MLP 推理开销）和**编辑困难**（隐式表示）。

### 3. 3DGS 的诞生（2023）

- **2023 年 8 月**：Inria（法国）、马克斯·普朗克研究所、Universität Tübingen 联合发表论文 *"3D Gaussian Splatting for Real-Time Radiance Field Rendering"*，发表于 **SIGGRAPH 2023**，获 **Best Paper**。
- **核心作者**：Bernhard Kerbl、Georgios Kopanas、Thomas Leimkühler、George Drettakis。
- **开源**：同步发布 CUDA 实现，迅速引爆社区。

### 4. 生态爆发（2023~2024）

| 时间 | 里程碑 |
|---|---|
| 2023.08 | 官方代码开源（CUDA + PyTorch） |
| 2023.09 | **SuperSplat** 等浏览器端编辑器出现 |
| 2023.10 | **Three.js / Babylon.js / PlayCanvas** 集成 3DGS 渲染 |
| 2023.11 | **GaussianEditor** — 支持语义编辑（用文本指令增删场景物体） |
| 2023.12 | **4D Gaussian Splatting** — 引入时间维度，支持动态场景 |
| 2024.01 | **Mip-Splatting** — 解决混叠/锯齿问题 |
| 2024.02 | **GaussianShader** — 法线、反射、折射效果 |
| 2024.03 | **GaussianSplats with Physics** — 高斯与刚体物理结合 |
| 2024.06 | **GaussianAvatar** — 动态数字人，可驱动表情/姿态 |
| 2024.09 | **Scaffold-GS** — 用锚点结构减少高斯数量，提升质量 |
| 2025~2026 | 压缩算法成熟（存储从 500MB → 10MB）、移动端实时渲染、WebGPU 实现 |

### 5. 当前状态（2026）

- **工业级应用**：Google Maps Immersive View、Niantic VPS、汽车厂商虚拟展厅
- **工具链成熟**：Polycam、Luma AI、Kiri Engine、Postshot 等 App 可一键生成 3DGS
- **Web 生态**：`@mkkellogg/gaussian-splats-3d` 等库让浏览器原生渲染成为可能

## 三、应用方向

### 1. 实时场景重建（最核心）

- **从照片重建**：用户上传 10~100 张照片，几分钟内生成可实时漫游的 3D 场景
- **产品代表**：Luma AI、Polycam、Kiri Engine、Gaussian Splatting Labs
- **优势**：比 NeRF 快 100 倍，且几何更锐利（没有 NeRF 的"糊"感）

### 2. 数字人与虚拟形象

- **GaussianAvatar**：用 3DGS 表示人脸/人体，支持表情和骨骼驱动
- **动态毛发/衣物**：比传统 Mesh 更自然地表达发丝、绒毛等细节
- **应用**：虚拟主播、数字人客服、元宇宙形象

### 3. VR/AR 与空间计算

- **Apple Vision Pro**：3DGS 是展示真实空间扫描数据的理想格式
- **混合现实**：将真实环境扫描为 3DGS，虚拟物体可正确遮挡/反射
- **6-DoF 视频**：4D Gaussian Splatting 实现自由视角视频

### 4. 自动驾驶与机器人

- **街景重建**：重建高精度城市环境用于仿真测试
- **传感器融合**：LiDAR 点云 + 图像联合优化 3DGS
- **占用网络**：用高斯表示动态障碍物，辅助路径规划

### 5. 文化遗产与数字孪生

- **博物馆**：文物/古建筑的高精度数字化，支持线上虚拟游览
- **房地产**：VR 看房，从几张照片生成可漫游的室内模型
- **工业巡检**：工厂设备的 3D 快照，远程检查设备状态

### 6. 游戏与影视

- **背景环境**：用 3DGS 渲染复杂自然场景（森林、城市），替代传统天空盒
- **预演（Previs）**：快速生成场景原型，导演可实时调整机位
- **体积特效**：烟雾、云朵的实时渲染（结合物理模拟）

### 7. 电商与广告

- **商品展示**：360° 可交互的商品模型，比传统转盘图更沉浸
- **虚拟试穿**：服装/配饰的 3D 展示，支持缩放查看材质细节

## 四、在 Three.js 中使用 3DGS

```javascript
// 使用 gaussian-splats-3d 库
import * as GaussianSplats3D from '@mkkellogg/gaussian-splats-3d';

const viewer = new GaussianSplats3D.Viewer({
    cameraUp: [0, 1, 0],
    initialCameraPosition: [-1, -0.5, -1],
    initialCameraLookAt: [0, 0, 0],
    rootElement: document.getElementById('canvas-container')
});

viewer.addSplatScene('path/to/scene.ply', {
    showLoadingUI: true,
    position: [0, 0, 0],
    rotation: [0, 0, 0, 1],
    scale: [1, 1, 1]
}).then(() => {
    viewer.start();
});
```

## 五、与 NeRF 的终极对比

| 维度 | NeRF | 3D Gaussian Splatting |
|---|---|---|
| **表示方式** | MLP 隐式场 | 显式高斯椭球 |
| **渲染速度** | 0.5~2 FPS | 100+ FPS |
| **训练速度** | 数小时~数天 | 数分钟~数十分钟 |
| **内存占用** | 较小（MLP 权重） | 较大（数百万高斯） |
| **编辑性** | 差（隐式场难修改） | 好（可增删单个高斯） |
| **抗锯齿** | 好（连续函数） | 需额外处理（Mip-Splatting） |
| **动态场景** | 困难 | 4D-GS 自然扩展 |
| **空洞填补** | 好（隐式插值） | 差（无高斯处无数据） |

## 六、总结

3D Gaussian Splatting 是 **2023 年以来计算机图形学领域最重要的突破之一**。它巧妙地结合了：
- **显式表示**的可编辑性
- **可微渲染**的数据驱动优化能力
- **光栅化**的硬件效率

使得"从照片到实时 3D 场景"的门槛从"研究级"降到了"消费级"。如果说 NeRF 证明了神经网络可以表示 3D 世界，那么 3DGS 则证明了**显式基元（高斯）+ 梯度优化**才是通往实时交互的正确路径。
