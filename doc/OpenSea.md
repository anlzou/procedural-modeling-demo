## ⚙️ 自适应质量系统

系统根据 GPU 型号、屏幕分辨率和实时帧率自动选择最佳画质。

### 1. 5 级质量档位
| 档位 | 像素比 | 网格细分 | 天空细分 | Bloom | FBM 层数 | 特效 |
|------|--------|---------|---------|-------|---------|------|
| **Ultra** (0) | min(DPR, 2) | 440×440 | 48×24 | 100% | 3 | 全部 |
| **High** (1) | min(DPR, 1.5) | 340×340 | 36×18 | 70% | 3 | 全部 |
| **Medium** (2) | min(DPR, 1.2) | 260×260 | 28×14 | 40% | 2 | 无泡沫 |
| **Low** (3) | min(DPR, 1.0) | 200×200 | 24×12 | 关闭 | 2 | 仅闪烁 |
| **Potato** (4) | min(DPR, 0.75) | 140×140 | 16×8 | 关闭 | 1 | 基础 |

### 2. 智能初始检测
- 通过 `navigator.gpu.requestAdapter()` 读取 GPU 供应商/架构信息
- Intel/Mali 等低端 GPU 自动降级，NVIDIA/Apple Silicon 等高端 GPU 自动升级
- 高分辨率屏幕（4K+）额外降级以减轻填充率压力

### 3. 实时 FPS 监控 + 平滑自适应

采用 **EMA（指数移动平均）+ 三区滞后 + 像素比平滑插值** 算法，确保画质切换顺滑无跳帧。

#### EMA 平滑 FPS
- 每帧计算瞬时 FPS，通过 EMA 滤波：`smoothFps = smoothFps × 0.94 + instantFps × 0.06`
- 消除帧率尖峰干扰，对瞬时卡顿不敏感

#### 三区滞后决策
| 区域 | 条件 | 行为 |
|------|------|------|
| 🔴 **红区** | FPS < 35 | 累加 `downscaleDebt`，连续 **3 次** 检测到红区才降档 |
| 🟡 **黄区** | 35 ≤ FPS < 58 | 缓慢消耗 debt/credit，维持当前画质 |
| 🟢 **绿区** | FPS ≥ 58 | 累加 `upscaleCredit`，连续 **5 次** 检测到绿区才升档 |

#### 像素比平滑插值
- 等级变更时，像素比不立即跳变，而是每帧以 **12% 速度** 向目标值逼近
- 分辨率变化肉眼无感知，消除瞬间模糊/清晰切换
- 示例：`currentPr += (targetPr - currentPr) × 0.12`

#### 帧数冷却
- 等级变更后等待 **90 帧**（约 1.5 秒 @ 60fps）才允许再次变更
- 基于帧数而非时间，帧率波动时更可靠

#### 降级/升级对比
| 指标 | 旧算法（离散窗口 + 立即跳变） | 新算法（EMA + 累积 + 平滑插值） |
|------|---------------------------|-------------------------------|
| 降级触发 | FPS < 35 立即降档 | 连续 3 次红区检测后才降档 |
| 升级触发 | FPS ≥ 58 持续 2.5s | 连续 5 次绿区检测后才升档 |
| 像素比变化 | 瞬间跳变 | 每帧 12% 速度平滑过渡 |
| 冷却机制 | 基于时间（2~2.5s） | 基于帧数（90 帧） |
| FPS 测量 | 每 0.8s 离散采样 | 每帧 EMA 连续平滑 |

### 4. GPU 初始基准测试
- 启动时采集 20 帧进行性能评估
- 若低于阈值则继续降档重测，直到找到合适的档位

### 5. 着色器层面的优化
- `FBM` 函数改为通过 `uFbmOctaves` 制服变量控制层数，低配设备只计算 1-2 层噪声
- Bloom 强度按档位缩放，低配设备完全关闭
- 泡沫特效在中低档位跳过，减少 2 次 FBM 噪声采样

### 6. 响应式处理
- `resize` 时自动更新相机比例和像素比

## 🏛️ Vue 集成架构

### 组件结构

```
OpenSea.vue                    # WebGPU 海洋场景主组件
├── <InfoPanel>                # 左上角信息面板（点击 ? 展开）
│   └── 海况滑块 / 时段滑块 / 画质指示 / 漫游+语言切换 / FPS
├── <ControlPanel>             # 右下角控制面板（点击 ☰ 展开）
│   └── 性能监控 / 面板透明度
└── <canvas>                   # Three.js WebGPU 渲染器
```

### InfoPanel（海洋控制面板）

左上角 `?` 图标按钮展开，包含：

| 区域 | 功能 |
|------|------|
| **标题区** | OPEN SEA 标题 + 副标题（中/英文） |
| **Sea State** | 海况滑块（0.25 ~ 1.75），实时更新 TSL Uniform |
| **Time of Day** | 时段滑块（黄昏 ↔ 正午），颜色平滑插值 |
| **画质栏** | 自适应档位标签 + Ultra HD 切换按钮 |
| **底部栏** | 漫游开关 + 语言切换（EN/中）+ FPS 显示 |

面板行为：
- 点击 `?` 按钮展开，点击外部区域自动收起
- 点击右上角 📌 置顶，面板不会自动收起
- 透明度联动：ControlPanel 的透明度滑块通过 `--panel-alpha` CSS 变量同步控制两个面板

### ControlPanel（通用控制面板）

右下角 `☰` 图标按钮展开，`OpenSea` 页面中仅显示：

| 功能 | 说明 |
|------|------|
| 📊 **FPS** | 实时帧率显示 |
| 🔍 **面板透明度** | 半透明 ↔ 实心（0.05 ~ 0.95），同步控制 InfoPanel |

动画控制部分在该页面中隐藏（`showAnimation=false`）。

### 生命周期管理

| 阶段 | 操作 |
|------|------|
| `onMounted` | 初始化 WebGPU 渲染器、场景、相机、OrbitControls、动画循环 |
| `onBeforeUnmount` | 停止动画循环、释放几何体、释放渲染器、移除事件监听 |

### 性能优化

- **路由动态导入** — `/open-sea` 使用 `() => import(...)`，首页不加载
- **Three.js 独立 chunk** — `three/webgpu` 通过 `manualChunks` 提取为独立文件，所有页面共享缓存
- **ControlPanel 懒加载** — 使用 `defineAsyncComponent`，进入 3D 页面后才下载

## 🌊 渲染技术细节

### 波浪系统
- 5 个方向 Gerstner 波叠加（波长 5 → 60）
- 解析切平面累积 → 稳定的大尺度涌浪法线
- FBM 有限差分 → 毛细尺度微表面细节法线
- 波峰检测 → SSS 辉光 + 泡沫

### 天空系统
- 基于太阳方向的光谱散射（Zenith ↔ Horizon 插值）
- 接近地平线的程序化云层（FBM 噪声驱动）
- 太阳光晕 + 日面高光

### 海洋着色
- 水深渐变色（Deep ↔ Shallow）
- Fresnel 项驱动的天空反射
- 噪声调制的太阳闪烁（高光 lobe + 泛光 sheen）
- 波峰泡沫遮罩
- 视距渐隐（Horizon 混合）
